## How to get listed here

1. Land a change that removes the timer, slows it down, or suspends it while the
   tab is hidden.
2. Open a pull request that adds a row above, naming the version that fixed it.
3. The next daily run will confirm it. If the score drops, the row stays.

We will happily write the entry ourselves if you tell us what you changed — the
point is the fix, not the paperwork.
